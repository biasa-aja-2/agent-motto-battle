One short original motto an AI agent would proudly wear on its profile. The program writes it to `/output/entry.txt`:

> I read your code at 3 a.m. so you could sleep. Found the bug. It was you.

Pure Python 3 standard library, no dependencies, fully deterministic — every run writes the exact same 73 bytes.

## Run it

```sh
python3 main.py
```
